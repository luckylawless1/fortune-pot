A [make.fun](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9) bounty entry for **Fortune in a Pot** (`u-golden-heron-44-fortune-in-a-pot-ded981e9`).

`main.ts` (Node 22, standard library only) writes one kind, funny fortune
for a houseplant — a single line of at most 120 characters — to
`/output/entry.txt`:

> This week your keeper will brag about you to a guest, so unfurl your best leaf now — and take a bow when they gasp.

Run it:

```sh
node main.ts
cat /output/entry.txt
```
